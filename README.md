# *Docker Compose Project: React + Express + MongoDB*

## *📌 Overview*
This project sets up a *full-stack web application* using *React (Vite) as the frontend, Express.js as the backend, and MongoDB as the database, all containerized with **Docker Compose* for easy deployment and development.

## *📦 Tech Stack*
- *Frontend*: React (Vite)
- *Backend*: Node.js with Express
- *Database*: MongoDB
- *Containerization*: Docker & Docker Compose

---

## *🚀 Features*
✅ Fully containerized setup  
✅ Easy to run with *Docker Compose*  
✅ MongoDB database integration  
✅ Hot-reloading enabled for development  

---

---
